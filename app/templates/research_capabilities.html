Research Capabilities

Infrastructure for experimental studies of AI teams in organizational contexts.

Interdependence as an Experimental Manipulation

Based on Saavedra, Earley, & Van Dyne (1993). The platform implements four task interdependence structures as executable coordination protocols — not labels — giving researchers precise experimental control over how work and information flow among agents.

  • Pooled — Agents work independently. Each agent receives the task and produces output without seeing others' work. Outputs are aggregated at the end of the simulation.
  • Sequential — Agents operate in a chain. Each agent receives the prior agent's output as input, building progressively on the team's collective work.
  • Reciprocal — Agents are split into two subgroups that operate in parallel within each round, then exchange outputs bidirectionally before the next round begins.
  • Team (Intensive) — All agents participate simultaneously in each round via a shared round-robin discussion, with full mutual visibility of all prior messages.

Team Task Library

Built-in tasks are drawn from organizational and team-research traditions. Each task has defined agent instructions and, where applicable, a scored ground truth for computing team accuracy (Spearman rank correlation against an expert reference).

  • Scored tasks (Lost at Sea, Desert Survival, Moon Landing) — produce a numeric agreement score per replication, enabling statistical comparison across conditions.
  • Unscored tasks (Hiring Decision, Ethical Dilemma) — produce full transcripts for qualitative analysis. Useful for studying argumentation, preference aggregation, or deliberation quality.
  • Custom tasks — researchers supply their own prompt. Can be marked scored or unscored. Supported in both Pure AI and HITL builders.

Human-in-the-Loop Experimental Design

The HITL builder supports studies in which a human participant observes an ongoing AI-team conversation, pauses it at a moment of their choosing or at researcher-defined checkpoints, and sends messages into the team. Researchers configure three dimensions of the intervention design:

  • Intervention timing — anytime (participant-controlled), between rounds only, or at scheduled checkpoints every N rounds.
  • Intervention target — the participant can message one specific agent, a selected subset, or the full team.
  • Framing to the AI — the platform presents human input to agents as a human teammate message, a system instruction, or advisory context (non-binding suggestion), controlling how the intervention is interpreted by the models.

Each HITL session generates a unique participant link. All human interventions are logged with timestamps and recipients, and are exportable alongside the full conversation transcript.

Data Capture and Export

Every run captures the following:

  • Task configuration, team structure, agent count, and model metadata
  • Token usage (input and output) and per-turn latency
  • Full conversation transcript with agent labels and round indices
  • Human interventions for HITL sessions (content, recipient, timestamp, event type)
  • Summary score where applicable (Spearman correlation against expert reference)

Data is exportable as JSON (full transcript + config) and CSV (per-event log). API keys are never stored on the server.

Simulation Scale

Pure AI studies support up to 1,000 replications per experiment run with configurable parallelism (concurrency limit). An optional random seed enables fully reproducible simulation sequences across conditions. All results are accessible from the run dashboard and individual transcript viewer.

HITL sessions are single-participant and run in real time over a WebSocket connection. Multiple concurrent HITL sessions are supported server-side.

Reference: Saavedra, R., Earley, P. C., & Van Dyne, L. (1993). Complex interdependence in task-performing groups. Journal of Applied Psychology, 78(1), 61–72.
